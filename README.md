# Shivam Pahwa | Karuja Arts

Portfolio site for Shivam Pahwa, muralist and graffiti artist based in Ludhiana, Punjab.

Plain HTML and CSS with a little JavaScript for the image viewer. No build step.

- Open `index.html` in a browser to view it locally.
- To publish, upload `index.html` and the `img/` folder to any static host.
- Fonts load from Google Fonts, so the page needs an internet connection.
